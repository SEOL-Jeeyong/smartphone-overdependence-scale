# 스마트폰 과의존 척도 (S-척도) 체크리스트

과학기술정보통신부 · 한국지능정보사회진흥원(NIA)의 표준 진단 척도 데이터를 기반으로 구축된 **스마트폰 과의존 척도(S-척도) 전용 체크리스트 웹페이지**입니다.

불필요한 사례나 긴 부가 정보 없이, **체크리스트와 점수 계산 및 판별**에만 집중하여 깔끔하고 직관적으로 사용할 수 있도록 제작되었습니다.

---

## 📋 지원하는 척도 및 판별 기준

### 1) 자기점검용 척도 (10문항, 40점 만점)
* **청소년 (만 10~19세)** : 고위험군 31점 이상 | 잠재적 위험군 23~30점 | 일반 사용자군 22점 이하
* **성인 (만 20~59세)** : 고위험군 29점 이상 | 잠재적 위험군 24~28점 | 일반 사용자군 23점 이하
* **보호자 (만 20~59세)** : 고위험군 29점 이상 | 잠재적 위험군 24~28점 | 일반 사용자군 23점 이하
* **고령층 (만 60세 이상)** : 고위험군 28점 이상 | 잠재적 위험군 24~27점 | 일반 사용자군 23점 이하

### 2) 관찰자용 척도 (9문항, 36점 만점, 1~3번 역채점 자동 적용)
* **유아 (만 3~5세)** : 고위험군 28점 이상 | 잠재적 위험군 24~27점 | 일반 사용자군 23점 이하
* **유·아동 (만 3~9세)** : 고위험군 28점 이상 | 잠재적 위험군 24~27점 | 일반 사용자군 23점 이하
* ※ 1~3번 문항(조절실패)은 **역채점(1번 선택→4점, 2번→3점, 3번→2점, 4번→1점)**이 자동으로 계산됩니다.

## 🌟 주요 기능
1. **간편한 대상 선택**:
   * 상단 버튼 클릭 한 번으로 `자기점검용`(청소년/성인/보호자/고령층)과 `관찰자용`(유아/유·아동)을 즉시 전환할 수 있습니다.
2. **엑셀 감성의 직관적인 체크 테이블**:
   * 각 문항의 1~4번 칸을 클릭하면 **노란색 하이라이트**로 강조되며 체크됩니다.
   * 우측 환산 점수 열에 실시간으로 배점(역채점 반영)이 계산됩니다.
   * 하단에 하위 요인별 소계(조절실패, 현저성, 문제적 결과) 및 전체 총점이 자동 집계됩니다.
3. **스마트폰(모바일) 전용 반응형 카드 UI 및 2×2 대형 터치 버튼**:
   * 모바일 화면(768px 이하) 접속 시 가로 표 대신 **세로형 문항 카드(`m-card`)**로 자동 전환되어 화면 잘림 없는 최적의 모바일 UX를 제공합니다.
   * 엄지손가락으로 탭하기 쉬운 **2열 2행(2×2) 대형 터치 버튼 타일(최소 64px 높이)**을 제공합니다.
   * 각 버튼에 원기호(①~④), 선택지 텍스트, 환산 점수 힌트(역채점 반영)를 명시하여 직관적인 응답이 가능합니다.
4. **실시간 응답 진행 상황 프로그레스 바 & 점수 요약**:
   * 상단에 `완료 문항 수 / 전체 문항 수 (진행률 %)` 게이지 바가 실시간으로 채워집니다.
   * 모바일 화면 하단에 하위 요인별 점수(조절실패, 현저성, 문제적 결과)와 총점을 깔끔한 그리드 카드로 실시간 집계합니다.
5. **실시간 판별 결과 리포트**:
   * 점수 합계에 따라 **일반 사용자군(초록)**, **잠재적 위험군(노랑)**, **고위험군(빨강)**으로 실시간 판정되며 맞춤 해석을 제공합니다.
6. **초기화 및 인쇄 기능**:
   * 상단의 [초기화] 버튼으로 모든 응답을 리셋할 수 있습니다.
   * [결과 인쇄] 버튼으로 A4 리포트 인쇄 또는 PDF 저장이 가능합니다 (인쇄 시 표준 표 형식으로 자동 출력).

## 💻 실행 방법

### 방법 1: 브라우저에서 직접 열기 (더블클릭)
1. 탐색기에서 `index.html` 파일을 더블클릭합니다.
2. Chrome, Edge, Safari 등 모든 모던 웹 브라우저에서 바로 동작합니다.

### 방법 2: 로컬 서버 실행 (선택 사항)
```powershell
cd "D:\0_sw-repo\스마트폰_과의존_예방_S척도"
python -m http.server 8080
```
웹 브라우저에서 `http://localhost:8080/index.html` 로 접속합니다.
